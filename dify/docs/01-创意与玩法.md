# 01 · 创意与玩法

## 1. 一句话

**把生活里最不值一提的破事，郑重其事地告上宇宙最高法院。**

## 2. 为什么这个点子好玩

大多数 AI 应用在解决「正经问题」：写周报、做客服、查文档。但人真正会截图分享的，往往是那些**一本正经的荒诞**。

《宇宙离谱法庭》抓住的就是这个反差：

- 原告的诉求极其小：猫凌晨蹦迪、室友的袜子、周一太讨厌、外卖少一双筷子；
- 法庭的态度极其大：有案号、有法条、有质证、有判决书、有前科档案；
- 法官的判决极其具体：不是「建议你沟通一下」，而是「判处被告连续七天于凌晨三点向原告公开道歉，并赔偿小鱼干三条」。

严肃的程序 × 荒诞的标的 = 天然的笑点，而且**每一场都能截图发群**。

## 3. 世界观

公元 3026 年，人类终于把「情绪价值」写进宪法。最高法院下设**宇宙离谱法庭**，专门处理那些「标的额不足一杯奶茶，但精神损害高达一个宇宙」的纠纷。

- **包大仁**：首席大法官，编号 JDG-3026。半文半白，自称「本官」，爱敲法槌（🔨），信条是「法律不问事小，只问离不离谱」。他不嘲笑原告，只嘲笑案件和被告。
- **书记员小合**：不露面。负责翻法典（seekdb）、查判例（seekdb）、记档案（PowerContext）。法官每次说「依《……法》第 XX 条」，都是小合刚刚检索出来的真条文。
- **《宇宙离谱法典》**：72 条，分 13 个案由：宠物、室友、时间、食物、科技、情感、天气、通勤、职场、家庭、自我、玄学、金钱。每条都有编号、量刑区间、附带民事赔偿。

## 4. 一局怎么玩

### 第一轮 · 立案

玩家：

> 我要起诉我的猫。它每天凌晨三点在我脸上蹦迪，还打翻我的水杯。

法官：

> 原告，本官闻之，猫能凌晨三点于人面庞上翩然起舞，实乃「猫主子蹦迪」之惯犯。依据【AB-001 宠物夜间蹦迪罪】，此行为确已构成犯罪。原告可有证据？

此时系统已经做了三件事：

1. 从玩家这句话里推断案由标签「宠物」；
2. 在 seekdb 里用「向量 + 全文 + 标签过滤」召回 `AB-001`、`AB-002` 等条文；
3. 用玩家 ID 去 PowerContext 找「上次开庭」的记忆（第一次当然没有）。

### 第二轮 · 质证

玩家：

> 证据？它踩我脸的时候留下了脚印，而且水杯现在还在滴水。

法官会传唤被告、代述一句被告的辩解，并继续援引法条；后端把「被告：原告的猫」「案由：宠物夜间蹦迪罪」写回案卷，供第三轮使用。

### 第三轮 · 宣判

玩家说「请判决」——或者什么都不说，第三轮也会强制结案。

后端按公式算刑期：

```text
基础值 = (法定下限 + 法定上限) / 2
系数   = 0.6 + 离谱指数/100        # 0.6 ~ 1.6
态度   = 认罪 0.8 / 卖惨 0.9 / 沉默 1.0 / 狡辩 1.2
累犯   = 每有 1 次前科，法定上限 +3 天
刑期   = clamp(基础值 × 系数 × 态度, 法定下限, 累犯上限)
```

模型只能给「建议值」，最终数字由后端夹回区间。这样既保留模型的即兴发挥，又不会出现「判处被告 999 天」的失控。

### 再次开庭 · 记忆

新建一个会话，仍然用同一个玩家 ID：

> 又是我。这次我要告周一，它每周都恶意到访，还带来早高峰。

法官：

> 本官记得你。上次你起诉那只猫，判了 7 天；这次告周一，看来是惯犯了。

这句「记得」不是把聊天记录重新塞进上下文，而是 PowerContext 里真实存储、按相关度召回的记忆。**换会话、换设备、隔一天再来，只要玩家 ID 不变，法官都记得。**

## 5. 让人想再玩一次的钩子

| 钩子 | 说明 |
| --- | --- |
| 72 条法典 | 每次起诉都可能翻出没见过的条文，比如「香菜擅自投放罪」「周一恶意到访罪」「锦鲤许愿不还愿罪」 |
| 判例库 | 法官会说「本院曾判……」，新玩家也能看到别人留下的判例，世界是连续的 |
| 前科系统 | 告得越多，称号越离谱：法庭新鲜人 → 初犯旁听生 → 法庭常客 → 诉讼惯犯 → 法外狂徒 |
| 累犯加刑 | 同一个玩家反复起诉，法定上限每次 +3 天，法官会拿这个调侃你 |
| 案号 | 真实的递增案号，第 1 案、第 2 案……可以截图收藏 |
| 被告拟人 | 猫、周一、袜子、共享单车、打印机都能被「传唤」，法官会代述它们的辩解 |

## 6. 几个可以直接抄的起诉状

- 我要告我室友的袜子，它在我枕头底下住了一个月，还拒绝搬走。
- 我要起诉周一，它每周都恶意到访，还带来早高峰和未读邮件。
- 我要告我们公司的打印机，它每次在我打合同的时候卡纸。
- 我要告香菜，它未经允许出现在我的牛肉面里。
- 我要告我的拖延症，它把我两小时能做完的事拖到了截止前二十分钟。

## 7. 边界与分寸

- 法官嘲讽的是**案件与被告**，不是玩家本人；不涉及真实人身攻击、隐私、未成年人。
- 判决是荒诞的，但不低俗；赔偿单位是「小鱼干」「一个完整周末」「一副降噪耳机」这类可执行的笑点。
- 玩家输入会原样进入提示词，后端只做法条编号校验与刑期夹取；如果输入包含明显违规内容，模型层会按 Dify 的敏感词配置处理（默认关闭，可按需开启）。

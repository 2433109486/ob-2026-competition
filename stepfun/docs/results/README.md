# Raw benchmark data

Generated by:

```bash
node scripts/bench-collections.mjs   # b1/b2/b3 independent collection builds
node scripts/repeat-bench.mjs        # repeated benchmark on one build
node scripts/optimization-bench.mjs  # batch size + refresh strategy
```

File names:

- `int8-wasm-b{1,2,3}.json` — INT8, WASM, one import + benchmark per build.
- `fp32-wasm-b{1,2,3}.json` — FP32 baseline, WASM.
- `fp16-webgpu-b{1,2,3}.json` — FP16, WebGPU.
- `fp32-webgpu-b{1,2,3}.json` — FP32 baseline, WebGPU.
- `repeat-*.json` — three benchmark iterations on the same collection (quality/latency stability).
- `optimization.json` — batch 1/4/8/16/32 and refresh-per-batch vs refresh-once.

Each build JSON contains:

```json
{
  "config": { "name": "...", "collection": "...", "backend": "wasm|webgpu", "dtype": "q8|fp16|fp32" },
  "imported": { "modelLoadMs": 0, "embedMs": 0, "writeMs": 0, "refreshMs": 0, "totalMs": 0, "verified": true },
  "benchmark": {
    "quality": { "recall5": 0, "ndcg5": 0, "mrr10": 0 },
    "latency": { "queryP50": 0, "queryP95": 0, "dbP50": 0, "dbP95": 0, "e2eP50": 0, "e2eP95": 0 },
    "perQuery": [{ "id": "q01", "recall5": 0, "ndcg5": 0, "mrr10": 0, "queryMs": 0, "dbMs": 0, "e2eMs": 0 }]
  }
}
```

The browser and environment are recorded in the `backend` block (`userAgent`,
`hardwareConcurrency`, actual device). Times are milliseconds.

These files are the source for `docs/benchmark.md` and `docs/technical-note.md`.
